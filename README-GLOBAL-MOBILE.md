# Colibrí Print · Sidebar Global Responsive V1

## Objetivo
Hacer la navegación administrativa más intuitiva y usable en PC, tablet y móvil.

## Cambios
- Sidebar fija y organizada por grupos en escritorio.
- Drawer lateral en tablet/móvil.
- Overlay y bloqueo de scroll.
- Botón Menú.
- Cierre por botón o ESC.
- Activo de página automático.
- Grupos colapsables y persistencia visual local.
- Áreas táctiles de mínimo 40–44 px.
- Safe-area para teléfonos con notch.
- Tablas y formularios con manejo responsive.

## No cambia
No cambia base de datos, consultas, rutas de negocio, cálculos, pagos, cotizaciones, órdenes ni funciones de producción.
